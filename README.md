AMAZON DEVELOPER HACKATHON 2026 - FRICTION LOG
Participant: 1st Year Student

Hi Amazon Developer Team,

As a 1st-year college student from India, this is my first time participating in a global developer hackathon. I successfully built and deployed a Smart Dashboard for the Fire TV track using HTML, CSS, and JavaScript. 

During my development journey, I documented the following developer friction points:

1. GITHUB INTERFACE FOR BEGINNERS: Since I didn't have a GitHub account before this hackathon, learning how to create a repository and understanding GitHub Pages for hosting took a sharp learning curve. 
2. FIRE TV SCREEN LAYOUT TESTING: Testing how a web application UI stretches or looks on a large smart TV screen using just a standard laptop browser resolution is quite difficult. It would be amazing if Amazon could provide an in-browser physical Fire TV layout simulator for web developers.
3. COMPLEX CLOUD TERMINOLOGY: When checking the initial AWS developer setup documentations, the language used is highly optimized for senior cloud professionals. Adding a simplified "One-Click Quick Start" section for college students and absolute beginners would make the onboarding experience much better.

Thank you for organizing this event and giving young developers a global platform to learn and build!

Best regards,
A Passionate 1st-Year Student Builder
